# Agent Harness Engineering: companion code

Code for **Agent Harness Engineering: Engineering Reliable Domain-Specific Agent Harnesses** by Praneeth Paikray.

The book builds one harness, chapter by chapter, for a fictional clinical-trial pre-screening task. This repository holds that harness as a small Python package, the tests behind every guarantee the book states, the recorded live-model runs the book reports, and one notebook per chapter.

| Chapter | Topic | Code | Notebook |
| --- | --- | --- | --- |
| 1 | What a domain-specific harness does | `ahe/ch01.py` | [chapter-01](chapter-01/chapter01.ipynb) |
| 2 | Turn domain work into executable contracts | `ahe/ch02.py` | [chapter-02](chapter-02/chapter02.ipynb) |
| 3 | Build the smallest useful runtime | `ahe/ch03.py` | [chapter-03](chapter-03/chapter03.ipynb) |
| 4 | Engineer the context layer | `ahe/ch04.py` | [chapter-04](chapter-04/chapter04.ipynb) |
| 5 | Design tools and the action boundary | `ahe/ch05.py`, `ahe/mcp_server.py` | notebook with the chapter |

## Layout

- `ahe/chNN.py` holds the code a chapter adds or changes. Each module imports the previous chapter's, so earlier chapters keep working. The book's listings are the regions between `# listing N.M` and `# end listing`; the book holds no copy of its own.
- `ahe/live.py` records live model calls. Nothing calls a model unless `AHE_LIVE=1` is set.
- `tests/` asserts every guarantee the book states. A sentence in the book that says "never" or "every" has a test here, or it is rewritten.
- `runs/` holds every live call the book reports, one JSON object per line, with the model id, date, prompt, reply, token counts, and cost. The book's tables replay these records, so you can reproduce them without an API key.
- `chapter-0N/` holds the notebooks, generated by `tools/build_notebooks.py` from the package.

## Run it

Python 3.10 or newer, standard library only for the package.

```bash
python -m venv .venv && source .venv/bin/activate
python -m pip install -e ".[dev]"
python -m pytest -q
jupyter lab chapter-01/chapter01.ipynb     # jupyter is not in [dev]; pip install jupyterlab
```

To call a live model, create `~/.config/ahe/openrouter.env` (never commit it):

```
AHE_BASE_URL=https://openrouter.ai/api/v1
AHE_API_KEY=...
AHE_MODEL=openai/gpt-6-luna
```

Any OpenAI-compatible endpoint works, including a Databricks workspace (`https://<workspace-host>/serving-endpoints`). Then start Jupyter with `AHE_LIVE=1`. Use your own experiment names so the book's records in `runs/` stay as they are.

## Scope

Every patient, protocol, marker, and threshold is fictional. The code shows how software behaves. It makes no clinical or enrollment decision, and passing its tests says nothing about fitness for clinical use.
