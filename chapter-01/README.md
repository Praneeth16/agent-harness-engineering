Open [chapter01.ipynb](chapter01.ipynb) and run all cells from a fresh kernel. The notebook imports `ahe/ch01.py`, runs the chapter's examples and fixtures, replays the recorded live runs from `runs/`, and gives the exercise solutions. This notebook is generated by `tools/build_notebooks.py`. Edit that script, not the notebook.
